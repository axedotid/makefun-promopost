# post-x-promote bounty entry

A minimal make.fun entry for the post-x-promote bounty. `POST.json` holds the
published X post URL, and `main.ts` (Node 22) copies that file into the output
directory (`$MAKEFUN_OUTPUT_DIR`, defaulting to `/output`), creating it if
needed. The program is fully offline with no network or external reads.
